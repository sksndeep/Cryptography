Instructions

A shift cipher replaces each letter with another letter a fixed number of positions away in the alphabet. Assume \(A = 0\), \(B = 1\), \(\dots\), \(Z = 25\). Wrap around after \(Z\).

Encryption: \(E(x) = (x + k) \pmod{26}\)
Decryption: \(D(x) = (x - k) \pmod{26}\)

Here, \(k\) is the shift key. Preserve spaces between words.

Cipher Types: Quick Guide and Illustrative Examples

1. Shift (Caesar) Cipher. Each letter is moved a fixed number of places. Encryption: \(E(x)=(x+k)\bmod 26\). For example, with \(k=3\), A maps to D and DOG maps to GRJ.

2. Affine Cipher. Each letter \(x\) is transformed using \(E(x)=(ax+b)\bmod 26\), where \(\gcd(a,26)=1\). Decryption uses \(D(y)=a^{-1}(y-b)\bmod 26\). For example, with \(a=5,b=8\), A maps to I and ABC maps to INS. The condition \(\gcd(a,26)=1\) ensures that \(a^{-1}\) exists modulo 26.

3. Vigenère Cipher. A repeating keyword supplies a different shift for each letter. For example, using key BAD with plaintext CAT gives ciphertext DAW (B=1, A=0, D=3).

4. RSA Encryption. A public-key system; encryption computes \(C=M^e\bmod n\) and decryption computes \(M=C^d\bmod n\). For a small illustrative example, if \(n=33,e=3,M=2\), then \(C=2^3\bmod 33=8\).

5. RSA Digital Signatures. A signer creates a signature using their private key; others verify it using the corresponding public key. In textbook RSA, a message block \(M\) is signed as \(S=M^d\bmod n\) and verified by checking \(S^e\bmod n=M\) (for correctly encoded blocks).

Part D: RSA Cryptosystem

RSA formulas

1. Choose two distinct prime numbers \(p\) and \(q\).
2. Calculate \(n = p \times q\).
3. Calculate \(\varphi(n) = (p - 1)(q - 1)\).
4. Choose \(e\) such that \(\gcd(e, \varphi(n)) = 1\).
5. Find \(d\) such that \(ed \equiv 1 \pmod{\varphi(n)}\).

Encryption: \(C = M^e \pmod{n}\)
Decryption: \(M = C^d \pmod{n}\)

Part E: RSA Digital Signatures

RSA Signing & Verification

To sign a message block \(M\) so that others know it came from Alice, she applies her private key \(d\): \(S = M^d \pmod{n}\).
Recipients verify the signature using Alice's public key \(e\): \(M = S^e \pmod{n}\).

Part F: Vigenère Cipher

Vigenère Cipher Principle

The Vigenère cipher uses a keyword consisting of letters with numerical equivalents \(k_1, k_2, \dots, k_m\). Plaintext blocks of length \(m\) are shifted element-wise by the key: \((p_i + k_i) \pmod{26}\) for encryption, and \((c_i - k_i) \pmod{26}\) for decryption.
